# InvoiceBill

React Native (Expo) app replicating the Trustopay Invoicing & Payments UI.

## Location
Created at: `m:\REACT NATIVE\InvoiceBill`

## Features
- **Onboarding** – 6-screen intro with Trustopay branding
- **Home** – Balance, quick actions (Scan QR, Transfer, Add Money, Withdraw), promo banner, recent transactions
- **Invoices** – List with status badges (paid, pending, overdue)
- **Quotes** – List with status (sent, accepted, rejected, etc.)
- **Customers** – Searchable list, add customer flow
- **Menu** – Profile, subscription, business settings
- **Bottom tab navigation** with badges
- **Modals** – Notifications, transaction/customer/invoice/quote detail

## Run the app
```bash
cd "m:\REACT NATIVE\InvoiceBill"
npm start
```
Then press `a` for Android, `i` for iOS, or `w` for web.

## Tech stack
- Expo SDK 54
- React Navigation
- Lucide React Native (icons)
- TypeScript
